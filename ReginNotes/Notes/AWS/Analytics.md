### 1. Amazon Athena

- **Benefits:** It is a serverless, interactive query service. There is no infrastructure to manage or database to set up. It integrates directly with [[Amazon Sagemaker]] (Athena ML), allowing you to write SQL statements that run ML inferences.

- **When to Use (AIP-C01 Triggers):** Look for phrases like _"Ad-hoc SQL queries on S3,"_ _"Analyze unstructured data in S3 without loading it into a database,"_ or _"Invoke machine learning models using SQL."_

- **Cost Structure:** Pay-per-query. You are charged based on the amount of data scanned (per TB). **Exam tip:**Compressing, partitioning, or converting data to columnar formats (like Parquet) significantly lowers Athena costs.

- **Use Cases:** Quickly exploring and validating raw CSV/JSON training datasets sitting in an S3 Data Lake before feeding them into SageMaker; using SQL to run anomaly detection on sales data via a pre-trained SageMaker model.


### 2. Amazon EMR (Elastic MapReduce)

- **Benefits:** A managed cluster platform that simplifies running big data frameworks, such as Apache Hadoop and Apache Spark. It handles the provisioning, configuring, and tuning of the underlying compute clusters.

- **When to Use (AIP-C01 Triggers):** Look for _"Big data processing,"_ _"Apache Spark/Hadoop workloads,"__"Complex data transformations,"_ or _"Migrating existing on-premise big data clusters."_
   
- **Cost Structure:** Pay a per-second rate for the EC2 instances running in the cluster, plus a small EMR management fee. You can use EC2 Spot Instances for the task nodes to drastically reduce costs.
   
- **Use Cases:** Heavy, distributed data preprocessing, data wrangling, and feature engineering on massive (petabyte-scale) datasets prior to training complex deep learning models.
   

### 3. AWS Glue

- **Benefits:** A fully managed, serverless Extract, Transform, and Load (ETL) service. It features **Glue Crawlers**that automatically scan data sources, infer schemas, and store that metadata in a centralized **Glue Data Catalog**.
   
- **When to Use (AIP-C01 Triggers):** Look for _"Serverless ETL,"_ _"Automated schema discovery,"_ _"Centralized Data Catalog,"_ or _"Prepare and transform data for ML automatically."_
   
- **Cost Structure:** Pay an hourly rate (billed per second) for crawlers discovering data, and pay for the ETL jobs running based on Data Processing Units (DPUs).
   
- **Use Cases:** Automatically crawling S3 buckets to define schemas for raw AI training data; running scheduled, serverless Spark jobs to clean, deduplicate, and format data before it is consumed by AI services.
   

### 4. Amazon Kinesis (Data Streams & Firehose)

- **Benefits:** The primary AWS service for real-time streaming data. It can continuously capture and store terabytes of data per hour from hundreds of thousands of sources.
   
- **When to Use (AIP-C01 Triggers):** Look for _"Real-time data,"_ _"Streaming data ingestion,"_ _"Clickstream analysis,"_ or _"IoT sensor data processing."_
   
- **Cost Structure:**
   
   - _Data Streams:_ Pay per provisioned shard hour or on-demand per GB ingested.
 
   - _Firehose:_ Pay-as-you-go based purely on the volume of data ingested (per GB).
  
- **Use Cases:** Ingesting real-time social media feeds, IoT telemetry, or application clickstreams, and feeding that data into an ML model for real-time inference (e.g., real-time fraud detection or dynamic personalized recommendations).
   

### 5. Amazon OpenSearch Service

- **Benefits:** A fully managed search and analytics engine. While historically used for <font color="#974806">full-text search and log analytics</font>, for AI exams, its most important feature is its **vector database capability** (k-NN search).
   
- **When to Use (AIP-C01 Triggers):** Look for _"Full-text search,"_ _"Log analytics,"_ _"Vector database,"_ _"k-Nearest Neighbor (k-NN) search,"_ or _"Retrieval-Augmented Generation (RAG)."_
   
- **Cost Structure:** Pay for the underlying EC2 instance hours (the nodes in the cluster) and the EBS storage attached to them.
   
- **Use Cases:** Storing text embeddings generated by Amazon Titan or Anthropic Claude (via Amazon Bedrock) and performing semantic similarity searches to fetch relevant enterprise documents for a Generative AI RAG architecture.
   

### 6. Amazon QuickSight

- **Benefits:** A serverless, fully managed Business Intelligence (BI) dashboarding tool. It includes ML-powered features like **QuickSight Q**, which allows users to ask questions about their data using natural language.

- **When to Use (AIP-C01 Triggers):** Look for _"Dashboards,"_ _"Business Intelligence,"_ _"Visualize data,"_ or _"Natural language queries on data."_
   
- **Cost Structure:** Pay per user. Authors (who create dashboards) have a fixed monthly fee. Readers have a pay-per-session model with a monthly cap, making it highly cost-effective for wide distribution.

- **Use Cases:** Visualizing the output of a machine learning model (e.g., plotting customer churn predictions on a map); allowing business executives to ask "What were our top-selling products last month?" using natural language without knowing SQL.
   

### 7. Amazon Managed Streaming for Apache Kafka (Amazon MSK)

- **Benefits:** A fully managed service that makes it easy to build and run applications that use Apache Kafka to process streaming data. It maintains strict compatibility with open-source Kafka.

- **When to Use (AIP-C01 Triggers):** Look for _"Migrate existing Kafka,"_ _"Open-source streaming tools,"_ or _"Complex, high-throughput event streaming architectures."_
   
- **Cost Structure:** Pay for the broker instance hours (compute) and the storage provisioned. There is also a serverless option where you pay per cluster hour and per GB of data processed.

- **Use Cases:** When an enterprise already heavily relies on Apache Kafka on-premise and wants to migrate to AWS to stream high-throughput, real-time data into a SageMaker feature store for continuous model training.
